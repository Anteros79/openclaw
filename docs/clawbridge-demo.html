Configuration

Simple, sane defaults

ClawBridge generates a secure Access Key during installation and auto-detects your networking environment. All options are overridable via config file or environment variables.

~/.clawbridge/config.json
// ClawBridge configuration — generated by installer
{
  // Access key used as ?key=<KEY> URL parameter
  "accessKey": "sk-cb-a3f9b2e1d8c7f4a6b0e5d2c8f1a9b3e7",

  // Server port — auto-selects next free port if occupied
  "port": 3000,

  // Networking mode: "auto" | "tunnel" | "vpn" | "local"
  "networking": "auto",

  // Optional: set for permanent Cloudflare Tunnel domain
  "cloudflareTunnelToken": "",

  // Cookie session auth settings
  "session": {
    "httpOnly": true,
    "secure": true,
    "maxAge": 86400000
  },

  // Brute-force protection: max 10 attempts / IP / 60s
  "rateLimiting": {
    "maxAttempts": 10,
    "windowMs": 60000
  },

  // Path to OpenClaw data directory (auto-detected)
  "openclawDataDir": "~/.openclaw"
}
Access Key
Randomly generated at install time. Passed as ?key=<KEY> URL param. Rotate by editing config and restarting.
Auto-Port
If port 3000 is occupied (e.g. by another service), ClawBridge automatically finds the next available port and updates the tunnel URL accordingly.
VPN Auto-Detect
Reads system network interfaces. If a Tailscale or WireGuard IP is found, skips the Cloudflare tunnel entirely and prints the private VPN URL instead.
Installation

Up and running in 30 seconds

Two installation paths: via the ClawHub skill registry (recommended) or a direct shell script. Both detect your environment, generate an Access Key, and print a ready-to-scan QR code.

What the installer does:
1
Detects environment: checks for Tailscale / WireGuard VPN; checks if port 3000 is free
2
Generates a cryptographically secure Access Key and writes it to ~/.clawbridge/config.json
3
Downloads the cloudflared binary if no VPN is detected
4
Starts the ClawBridge server, establishes tunnel, and prints the ready URL + terminal QR code
5
On macOS: registers a launchd service for automatic startup. On Linux: optionally installs a systemd unit.

Security

Private by design

ClawBridge was built with a local-first security model. No telemetry, no cloud account required, no data ever leaves your host without your control.

🔒
100% Local Data
Reads agent logs, memory files, and session data directly from disk on your gateway host. Nothing is uploaded to any cloud service. Your data never leaves the machine.
🕶️
No IP Exposure
When using the Quick Tunnel mode, Cloudflare acts as a proxy. Your real server IP is never revealed to the client device — only the ephemeral trycloudflare.com subdomain is exposed.
🍪
HttpOnly Cookie Auth
Session tokens are stored in HttpOnly, Secure cookies — never accessible via JavaScript. Prevents XSS token theft. Sessions expire after 24 hours by default.
🛡️
Brute-Force Protection
Per-IP rate limiting caps login attempts at 10 per 60-second window. Automated scanning tools are blocked immediately. Configurable thresholds in the config file.
🔑
Random Access Key
A 32-byte cryptographically secure random key is generated at install time and embedded in the access URL. Rotate it at any time by editing config.json and restarting.
